## Etalogía

Etalogía builds tools that turn academic submissions into publication-ready
books. The first of them sets conference proceedings: one path from the
submission form to a typeset volume, without anyone having to touch LaTeX.

By [**David Garzón Ramos**](https://dgarzonramos.com) · [etalogia.co](https://etalogia.co)

---

Work in this organisation is private and is not open source. Each repository
states its own terms in its `NOTICE`, and, where a licence has been granted, in
its `LICENCE`. Unless a repository says otherwise, all rights are reserved to
